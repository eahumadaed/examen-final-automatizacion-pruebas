# ReservaLab - Examen Final de Automatizacion de Pruebas

**Estudiante:** Edinson Ahumada Gallardo  
**Asignatura:** Automatizacion de Pruebas

ReservaLab es una aplicacion Java/Maven creada para demostrar de punta a punta un flujo de control de versiones, pruebas automatizadas, integracion continua y despliegue Blue-Green con rollback.

La documentacion completa y las evidencias se incorporaran en los siguientes avances del proyecto.
