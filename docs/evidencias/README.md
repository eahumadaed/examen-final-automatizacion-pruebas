# Evidencias

Este directorio contiene capturas y logs obtenidos desde ejecuciones reales del proyecto.

- `selenium-reserva-confirmada.png`: navegador Chrome luego de completar la prueba de aceptacion.
- `maven-verify-local.log`: salida local de pruebas unitarias y de integracion.
- `blue-green-local.log`: historial local con deploy Blue, deploy Green, rollback y limpieza.
- `github-actions-ci-cd.png`: ejecucion exitosa de los tres jobs en GitHub Actions.
- `github-actions-run.log`: log descargado de la ejecucion remota.
- `github-actions-run-summary.txt`: datos identificadores del workflow remoto.

GitHub Actions publica ademas tres artefactos: reportes JUnit, evidencia Selenium y evidencia Blue-Green/rollback.
